# make-knowledge-cards

把粘贴的文章或本地 Markdown / TXT 文件，转换成 5–8 张忠实原文的知识卡片。每张卡片只讲一个知识点，包含：**标题、核心知识、简明解释、例子或自测问题**。

该 Skill 只使用原文信息：不编造、不补充外部知识、不去重前不凑数。信息不足时只输出能提取的卡片数量。

## 特性

- 一张卡片一个知识点，重复内容合并，证据数字归入它所支撑的论断
- 观点类文章把主张归属给作者，不把作者的断言当作已证实事实
- 原文没有例子时，改为一道答案在原文中的自测题
- 数量按信息密度决定：不足 5 张时少于 5 张并说明原因，不强行凑数
- 纯指令驱动，无脚本、无外部依赖

## 使用方法

1. 将 `skills/make-knowledge-cards` 复制到你的 skills 目录（WorkBuddy 项目技能为 `.workbuddy/skills/`，Codex 为 `~/.codex/skills/`）。
2. 直接粘贴文章正文，或给出本地 `.md` / `.txt` 文件路径，例如：

   > 请把这篇文章做成知识卡片：（粘贴正文）
   >
   > 或：请把 `./notes/article.md` 做成知识卡片

3. Skill 直接输出卡片，无需额外标题或前言。

暂不支持：网页抓取、PDF、Anki、图形界面。仅给网址时不会抓取，会提示粘贴正文或保存为本地 `.md` / `.txt`。

## 输入示例

```text
白天学到的新知识最初存放在海马体中，这里像一块临时缓存，容量有限且容易被覆盖。夜间睡眠时，海马体会把信息重新播放给大脑皮层，这个过程称为"重放"，它让记忆更稳定。研究发现，学习新词后经历慢波睡眠的人，第二天回忆成绩比熬夜的人高出约20%。连续两晚只睡4小时的人，新学词汇的保留率下降约40%，因此考前通宵并不能提高记忆效果。20到30分钟的午睡足以让海马体完成一轮重放，但超过60分钟进入深睡眠后醒来会有睡眠惰性。
```

## 输出示例

### 卡片 1：夜间重放把信息转入皮层长期存储

- **核心知识**：睡眠期间海马体把白天信息重新播放给大脑皮层，这一过程称为"重放"，它使记忆更稳定。
- **简明解释**：海马体原本是一块容量有限、容易被覆盖的临时缓存；重放把信息转移到大脑皮层的长期存储区。
- **例子或自测问题**：自测：什么是"重放"？

### 卡片 2：慢波睡眠对陈述性记忆尤其重要

- **核心知识**：慢波睡眠对陈述性记忆尤其重要。
- **简明解释**：学习新词后经历慢波睡眠的人，第二天回忆成绩比熬夜的人高出约20%。
- **例子或自测问题**：自测：学习新词后经历慢波睡眠的人，第二天回忆成绩如何？

### 卡片 3：睡眠不足会削弱新学词汇的保留率

- **核心知识**：连续两晚只睡4小时会明显损害记忆巩固。
- **简明解释**：睡眠不足时海马体的重放活动明显减少，新学词汇的保留率下降约40%。
- **例子或自测问题**：自测：连续两晚只睡4小时对新学词汇有什么影响？

### 卡片 4：考前通宵不能提高记忆效果

- **核心知识**：考前通宵并不能提高记忆效果，反而会削弱已经学过的知识。
- **简明解释**：由于睡眠不足会损害重放与记忆保留，通宵无助于提升记忆。
- **例子或自测问题**：自测：考前通宵对已学知识有什么影响？

### 卡片 5：午睡效果取决于时长

- **核心知识**：20到30分钟的午睡足以完成一轮重放，超过60分钟则会出现睡眠惰性。
- **简明解释**：短午睡能让海马体完成重放；超过60分钟进入深睡眠后醒来，短期内反而难以集中注意力。
- **例子或自测问题**：自测：多长的午睡足以完成一轮重放？超过60分钟醒来有什么问题？
